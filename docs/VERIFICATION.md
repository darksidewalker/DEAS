## Rust video source inspection (0.1.52, development)

PP2a/W8a1 is implemented as a bounded source-inspection feature, not video inference/rendering or full W8a preparation. The owner’s standalone-video requirement is now explicit in the project rules and plans: Rust processing/inference integration, no Go or Python worker. Existing ComfyUI image recipes remain separate.

- New `video_post.rs::native_video_post_inspect(title)` accepts only a validated native chooser title. No frontend source/executable/argv is accepted. Registration, module export, dedicated permission and main-window capability are wired; `src-tauri/README.md` documents the seam. After selection it checks supported container magic and stable regular local-file identity, rejects symlinks/reparse/device/network paths as applicable, and runs native FFprobe with fixed demuxer/protocol limits, no MOV external data references, bounded probing/allocation/stdout/stderr and a 10-second deadline. A single native permit prevents overlapping inspection; its blocking owner cleans/reaps the owned process even if the IPC waiter disappears. Source metadata inspection is not a security sandbox against hostile same-user filesystem mutation.
- Exact rational-rate parsing avoids float-derived FPS; dimensions, stream counts, known duration and pixel/color/field metadata are validated. Conservative blockers cover cadence, field order, pixel aspect, dimensions, pixel format, alpha, rotation/display matrices and HDR/wide-gamut/unknown color. Matching header rates do not prove CFR; `timingVerified:false` and `processingReady:false` are unconditional. Shared Logs receive fixed severity/origin/operation UUID/outcome, not source paths/names or raw tool stderr.
- The Post-Processing component invokes only on an explicit chooser click, preserves the previous result on cancel, excludes duplicate clicks, ignores unmounted replies and shows errors without changing image settings or submitting work. Its snapshot is view-local. Independent source review found missing frontend SAR blocker labels; `nonSquarePixels` and `pixelAspectUnknown` now have six-language labels and are included in the focused UI matrix/browser cases. No remaining native source-review blocker was reported. The existing Windows spawn-before-Job-assignment limitation remains disclosed; Windows execution is not established by source review.
