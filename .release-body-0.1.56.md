## DEAS 0.1.56

**One build everywhere.** `video-upscale` is now a default Cargo feature: every Linux and Windows DEAS binary includes the native TVE spatial engine (True Video Enhancer, Rust ONNX inference). No more separate `deas-linux-amd64-video-upscale` variant — the retired binary is gone.

Engine use stays an explicit runtime opt-in (TVE settings + trusted runtime/model binding): nothing is bundled, nothing is auto-downloaded, no GPU/ONNX initialization at startup.

Built on CachyOS / RTX 5090 host from the tagged commit:
- `deas-linux-amd64` — full feature set (default features incl. video-upscale), direct glibc floor 2.39, dynamic webkit2gtk-4.1/libmpv/gstreamer.
- `deas.exe` — Windows MSVC cross-build (cargo xwin), unsigned, first real Windows launch is the acceptance test.
- `SHA256SUMS` verified with `sha256sum -c`; `BUILD-MANIFEST.json` records commit, tree, toolchain, targets, glibc floor.

Gates at this build: full Vitest suites, tsc, serial cargo tests (incl. native video-post suite running with the engine enabled), fmt/clippy (lib+bins+examples), Windows-MSVC `--all-targets` crosscheck, staged GUI launch probe.
